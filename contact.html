FAQs

Is EduBridge completely free?

Yes! EduBridge is a student project aimed at providing free education to all. All resources, lessons, and career guidance are free.

Is my data safe?

All progress data is stored only in your browser's local storage. No data is sent to any server in this demo.

Can I use it offline?

Offline access is planned for a future version. The current demo requires an internet connection for fonts.

Is this an IBM project?

EduBridge is a student initiative inspired by UN SDG 4, created as part of an IBM-associated academic presentation.
